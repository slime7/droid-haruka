Compatibility

先确认你的环境。

桌面端支持 64 位 Windows 与 Linux，设备端最低为 Android 11。macOS 暂不在支持范围内。

Before you connect

几个常见问题。

需要 root 手机吗？+

不需要。基础连接、设备管理与应用列表可通过 ADB 使用；画面采集、电脑接管输入法等部分能力需要 Shizuku 授权。

支持 macOS 吗？+

不支持。当前只发布 Windows 10 / 11 x64 与 Linux x64 版本，没有 macOS 安装包。

手机要怎么连接？+

可先通过 USB 开启调试后连接，也可使用无线调试配对。设备端 App、scrcpy 采集器和 adb 都会随桌面端安装包准备。

更新从哪里来？+

安装版从 GitHub Releases 检查更新。发布页同时提供 SHA-256 校验文件，便于核对下载内容。
